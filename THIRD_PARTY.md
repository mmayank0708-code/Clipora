# Third-party notices

Clipora includes the following open-source material. Their licenses require these notices to stay with the project.

## Caption style values
Some caption style values in `clip.py` come from Cutawan's caption table (MIT licence): https://github.com/JeremySNR/cutawan

## Models (`models/`)
- `yunet.onnx`: YuNet face detector, OpenCV Zoo (https://github.com/opencv/opencv_zoo), MIT licence.
- `face.tflite`: MediaPipe BlazeFace short-range, Apache 2.0.
- `object.tflite`: MediaPipe EfficientDet-Lite object detector, Apache 2.0.
- `face_landmarker.task`: MediaPipe Face Landmarker, Apache 2.0.

## Fonts (`fonts/`)
Anton, Archivo Black, Bangers, Bebas Neue, Bowlby One, Courier Prime, Lilita One, Montserrat, Noto Sans (Arabic, Devanagari), Poppins and Righteous are licensed under the SIL Open Font License 1.1. Each font's licence text is in the matching `OFL-*.txt` file in `fonts/`.

## Python packages
Installed at setup from `requirements*.txt`. Each keeps its own licence.
